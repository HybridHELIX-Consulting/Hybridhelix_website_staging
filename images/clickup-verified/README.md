# ClickUp Verified Consultant badges

Official badge assets from the ClickUp Verified Consultant program. Source of
record is the HybridHELIX SharePoint branding library:
`Branding Guide / ClickUp Verified Consultant / Assets from ClickUp / Verified Badges`.

## These are not our marks

The badges are ClickUp's intellectual property, licensed to us for use while we
hold verified status. That carries real constraints:

- **Do not recolor, restretch, rotate, crop, or add effects.** Use the supplied
  variant that fits the background.
- **Do not place a badge anywhere it implies ClickUp endorses a specific claim,
  outcome, or price.** It certifies that we are a verified consultant. Nothing
  further.
- **Respect the clear space and minimum size** defined in the source brand
  guidance. When in doubt, give it more room.
- **If verified status ever lapses, the badges come off the site.** Whoever
  handles that change should search the repository for `clickup-verified` to
  find every usage in one pass.

## Intended placement

Credibility surfaces — the credibility page, the homepage proof band, and the
footer trust row. Not the hero. A verification badge is supporting evidence,
not a headline.

## Format

Prefer SVG. It scales cleanly at any size, stays crisp on high-density displays,
and costs almost nothing to serve. Keep a PNG fallback only if a specific
surface actually needs one.
