# HybridHELIX brand assets

Our own marks and original graphics. We own these and control how they are used.

## Naming

Lowercase, hyphenated, descriptive. Include the variant when there is more than
one: `logo.png`, `logo-mono-light.png`, `wordmark-horizontal.svg`.

## Palette reference

For anyone producing new assets to match:

| Role | Hex |
| --- | --- |
| Dark navy | `#1a2b3c` |
| Near black | `#0a0e14` |
| Off white (text) | `#f0f4f8` |
| Cyan (primary accent) | `#4dbfe0` |
| Dark green | `#2d8b4e` |
| Lime (secondary accent) | `#8cc63f` |
